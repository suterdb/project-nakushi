# ADR-001: Linet 핵심 설계 결정

**Date**: 2025-02  
**Status**: Accepted  
**Project**: Linet (incubations/linet)

---

## Context

Linet은 단 한 줄로 소통하는 커뮤니티 서비스다.  
초기 설계에서 여러 상충 관계를 명확히 결정해야 했다.  
이 ADR은 그 결정들을 기록하고 근거를 남긴다.

---

## Decisions

---

### 결정 1: 사용자 중심이 아닌 태그(콘텐츠) 중심 피드

**결정**: 팔로우/팔로워 구조 없음. 태그 기반 피드만 운영.

**대안**:
- 사용자 팔로우 기반 피드 (트위터 모델)
- 알고리즘 추천 피드

**선택 이유**:
- 사람이 아닌 생각 자체가 발견되어야 한다는 철학
- MVP 복잡도 감소
- 신규 사용자의 "팔로할 사람이 없다" 문제 회피

**Trade-off**:
- 개인화 피드 없음 → 초기에는 콘텐츠 다양성이 오히려 장점
- 충성 사용자의 특정 작성자 팔로우 욕구 충족 불가

**Rollback Plan**:  
사용자 팔로우 기능은 독립 모듈로 설계. 태그 피드를 기본으로 유지한 채 추가 가능.

---

### 결정 2: 콘텐츠 멘션만 허용 (사용자 멘션 불가)

**결정**: `>>콘텐츠ID` 형식만 허용. `@사용자` 불가.

**대안**:
- 사용자 멘션 허용 (일반적인 소셜 미디어 모델)
- 멘션 기능 전체 제외

**선택 이유**:
- 사용자 노출 최소화 철학과 일관성
- 콘텐츠 간 연결에 집중 → 아이디어 네트워크 형성
- 사용자 멘션은 관계 기반 동학을 만들어 복잡도 증가

**Trade-off**:
- 특정 사람에게 직접 응답하는 방식 없음
- "이 사람의 글에 답한다"는 맥락이 불분명해질 수 있음

**Rollback Plan**:  
콘텐츠 멘션 시스템이 안정화되면 사용자 멘션을 별도 레이어로 추가 검토.

---

### 결정 3: 외부 링크 직접 노출 금지

**결정**: 외부 URL은 내부 콘텐츠로 변환 후 멘션으로만 참조.

**대안**:
- 외부 링크 그대로 노출 (일반적 방식)
- 링크 없이 텍스트만 허용

**선택 이유**:
- 텍스트 중심 원칙 유지
- 링크 어뷰징 / 스팸 방지
- 콘텐츠 품질 통제

**Trade-off**:
- 링크 공유 UX 마찰 증가
- 내부 변환 로직 구현 비용

**Rollback Plan**:  
링크 변환 실패율이 20% 초과 시 메타 타이틀만 표시하는 경량 모드로 전환.

---

### 결정 4: LLM 자동 태깅 (사용자 태그 입력은 보조)

**결정**: 태그는 LLM이 자동 생성. 사용자는 자동완성 기반으로 수동 추가 가능.

**대안**:
- 사용자가 직접 태그 입력 (해시태그 방식)
- 태그 없이 전문 검색만 제공

**선택 이유**:
- 태그 입력 마찰 제거 → 작성 경험 단순화
- LLM 수준이 이미 실용적 품질에 도달
- 유사 태그 그룹화로 검색/추천 품질 향상 가능

**Trade-off**:
- LLM 호출 비용 (per-post)
- 태그 오류 시 사용자 수정 UX 필요

**Rollback Plan**:  
LLM 태깅 비용이 임계점 초과 시 규칙 기반 태깅으로 폴백. 사용자 수동 태그를 기본으로 전환 가능하도록 설계 유지.

---

## Consequences

- 시스템은 처음부터 **태그 인덱스**가 핵심 인프라
- 사용자 테이블은 최소 컬럼으로 설계 (프로필 확장 없음)
- LLM 호출은 작성 시점에만 발생 (피드 조회 시 불필요)
