# 🧭 Nakushi Progress Guide System (Add-on)

This add-on turns Project Nakushi from a *static repository* into a *stateful guide system*.

It introduces:
- a global Stage Map (`/ops/stage-map.md`)
- per-incubation Stage Status (`/incubations/<name>/stage.md`)
- templates for the "next artifacts"
- prompts that let GPT/Claude infer "what's next" from the repo state

> Goal: Any AI agent can read the repo, determine the current stage, and propose (or generate) the next artifacts.
