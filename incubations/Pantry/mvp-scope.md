# MVP Scope — Pantry

## One-line MVP

사용자의 보유 재료 목록을 기반으로 특정 레시피의 재료를 AI가 필수/대체/생략 가능으로 분류하고, 구매 리스트와 최종 변환 레시피를 제공하는 웹 서비스.

## In Scope (max 3 flows)

| Flow | User action | System behavior | Output |
|---|---|---|---|
| 1 | 보유 재료 직접 입력 | 재료 목록을 세션에 저장 | 저장된 재료 목록 확인 화면 |
| 2 | 만들고 싶은 레시피 입력 (재료 목록 포함) | AI가 레시피 재료 × 보유 재료를 비교하여 필수/대체 가능/생략 가능으로 분류 | 분류 결과 + 필수 구매 목록 |
| 3 | 생략 가능 재료 컨펌 (Y/N 선택) | 컨펌 결과를 반영하여 최종 변환 레시피 생성 | 내 재료 기반 최종 레시피 출력 |

## Out of Scope (not now)

- 회원제 / 소셜 로그인
- 재료 잔량 추적 및 자동 감산
- 레시피 히스토리 저장
- 추천 레시피 피드 (보유 재료 기반)
- 영수증/인보이스 OCR 파싱
- 외부 레시피 API 연동
- 쇼핑 링크 제휴

## Validation Criteria (measurable)

- [ ] 경량 모델(Haiku급)로 재료 분류 정확도 80% 이상 (10개 레시피 수동 평가)
- [ ] 재료 분류 응답 시간 3초 이내
- [ ] 실제 사용자 3인 이상 테스트 후 "유용하다" 응답

## Assumptions

- 레시피는 사용자가 직접 텍스트로 입력한다 (크롤링, 외부 API 없음)
- MVP는 세션 기반으로 운영 — 서버 재시작 시 재료 목록 초기화
- 경량 모델(Claude Haiku급)의 요리 도메인 이해도가 재료 분류에 충분하다
- 프롬프트 튜닝만으로 필수/대체/생략 분류 품질 확보가 가능하다
