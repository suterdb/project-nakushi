# Normalized Input — Pantry

## Problem (one paragraph)

고물가 시대에 1인·2인 가구의 자취 요리 필요성이 높아졌으나, 기존 레시피 서비스는 '레시피 전달' 수준에 머문다. 실제 요리 역량은 레시피를 내 상황(보유 재료)에 맞게 변주(adapt)할 수 있는 능력인데, 어떤 재료가 필수인지·대체 가능한지·생략해도 되는지를 판단해주는 서비스가 없다.

## Target user

1인·2인 가구 중 직접 요리를 하고 싶지만 냉장고 속 재료로 레시피를 맞추는 것이 어려운 사람. 특히 식재료를 낭비하지 않으면서 합리적으로 요리하고 싶은 사용자.

## MVP (one-line)

사용자가 보유 재료를 등록하면, AI가 특정 레시피의 재료를 필수/대체/생략 가능으로 분류하고 구매 리스트를 제공한다.

## MVP flows (max 3)

1. 사용자가 현재 보유 재료를 입력 → 재료 목록 저장
2. 사용자가 만들고 싶은 레시피를 입력 → AI가 재료를 필수/대체/생략 가능으로 분류
3. 필수 구매 재료 리스트 제공 + 생략 가능 재료 컨펌 → 최종 변환 레시피 출력

## Validation criteria (measurable)

- [ ] 경량 모델(Haiku급)로 재료 분류 정확도 80% 이상 달성 (수동 평가 10개 레시피 기준)
- [ ] 사용자 3인 이상의 실제 사용 피드백에서 "유용하다" 응답
- [ ] 재료 분류 1회 응답 시간 3초 이내

## Constraints

- 경량 모델(Haiku급) 우선 — Sonnet/Opus는 비용 구조 검증 전까지 사용 지양
- MVP는 회원제 없이 세션 기반으로만 운영
- 레시피 소스는 사용자 직접 입력으로 시작 (외부 API 연동은 Post-MVP)
