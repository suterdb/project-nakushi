# MVP Scope — Linet

## 핵심 플로우 (3개 이하)

### Flow 1: 이슈 피드 수집 및 노출
- 지정된 RSS 소스(언론사 등)에서 주기적으로 신규 기사를 수집한다.
- LLM이 기사를 한 줄로 요약하고 태그를 자동 생성한다.
- 수집된 이슈가 이슈 피드 섹션에 실시간 노출된다.

### Flow 2: 사용자 작성 및 피드 노출
- 사용자가 140자 이내 한 줄을 입력한다.
- LLM이 자동으로 태그를 추천한다.
- 전송 시 작성 피드 상단에 즉시 반영된다.

### Flow 3: 반응 (공감/멘션)
- 이슈 카드·작성 카드 모두에 대해 공감(❤️) 가능.
- 💬 클릭 시 해당 컨텐츠를 멘션하는 입력창이 열리고, `>><contentID>` 형식으로 연결된다.

## 수집 정책 (신규 확정)
- **RSS 소스만 사용한다. 크롤링은 하지 않는다.**
- 1차 소스: 마이데일리 KBO(`kbo_rss.xml`), 스포츠경향 국내야구(`baseball_korea-baseball`) — 국내 프로야구로 한정.
- RSS를 제공하지 않는 소스(대부분의 대형 커뮤니티)는 이번 범위에서 제외한다.
- 비RSS 소스를 RSS 형태로 가공/제공하는 것(예: 커뮤니티 RSS 추출 플랫폼)은 Linet과 분리된 별도 프로젝트로 취급하며, 여기서 다루지 않는다.

## Out-of-Scope (MVP에서 제외)
- 크롤링 기반 수집 전체
- RSS 미제공 커뮤니티(디시, 펨코, 클리앙, 오유, 인벤, 더쿠, 뽐뿌 등) 소스 확장
- 사용자 프로필 페이지, DM, 알림, 팔로우/팔로워
- 이미지/영상 업로드, 외부 링크 직접 노출
- 모바일 앱 (웹 우선)

## 검증 범위 (폐쇄 알파 기준)
- 이번 라운드는 **"수집→태깅→노출→반응" 파이프라인과 UI/UX가 실제로 동작하고 쓸만한지**를 폐쇄 알파 테스터 대상으로 확인하는 것이 목표.
- `problem.md`의 "커뮤니티 화제성/포털 실검 대체"라는 장기 가설은 이번 라운드에서 검증하지 않는다 — 소스가 언론사 RSS(KBO)로 한정되어 있기 때문. 해당 가설 검증은 소스 확장 이후 별도 라운드로 미룬다.
- 알파 테스트 기준 (측정 대신 정성 확인):
  - 이슈 피드가 최소 하루 단위로 자연스럽게 갱신되는가
  - 알파 테스터가 이슈 카드에 공감/멘션 반응을 자발적으로 남기는가
  - 작성 피드와 이슈 피드가 공존하는 화면 구조가 혼란 없이 이해되는가
