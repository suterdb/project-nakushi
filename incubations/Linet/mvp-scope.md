# MVP Scope — Linet

## One-line MVP
단 한 줄을 작성하면 LLM이 태그를 달고, 실시간 피드에 올라가며, 다른 콘텐츠와 멘션으로 연결된다.

## In Scope (max 3 flows)

| Flow | User action | System behavior | Output |
|---|---|---|---|
| 1. 작성 | 하단 입력창에 140자 이내 한 줄 입력 후 전송 | LLM 자동 태그 생성, 피드 상단에 즉시 노출 | 태그 포함 콘텐츠 카드 |
| 2. 발견 | 피드 스크롤 또는 태그 클릭 | 5초 주기 신규 콘텐츠 추가, 태그 기반 피드 필터링 | 관심사 기반 피드 |
| 3. 반응 | ❤️ 공감 또는 💬 멘션 작성 | 공감수 즉시 반영, 멘션 관계 연결 및 원글 멘션수 갱신 | 콘텐츠 간 연결망 |

## Out of Scope (not now)
- 사용자 팔로우 / 팔로워
- 사용자 멘션 (`@user`)
- DM / 채팅
- 알림 시스템
- LLM 링크 요약 (비용 문제로 제외, 메타 타이틀만 표시)
- 수동 태그 자동완성 (자동 태깅 검증 후 추가)
- 모바일 앱 (웹 우선)

## Validation Criteria (measurable)
- [ ] 첫 방문자 중 30% 이상이 실제로 한 줄을 작성한다
- [ ] LLM 자동 태그 "적절하다" 응답 70% 이상 (초기 사용자 인터뷰 5~10명)
- [ ] 전체 게시물 중 15% 이상이 멘션을 포함한다 (2주 베타 기준)
- [ ] "누가 썼는지 몰라도 괜찮다" 반응 과반 (사용자 노출 최소화 검증)

## Assumptions
- LLM 태깅 비용은 초기에는 per-post 외부 API로 감수 가능하다
- 실시간 피드는 5초 폴링으로 충분하다 (WebSocket은 이후)
- 소셜 로그인 1종으로 인증 마찰을 최소화할 수 있다
- 외부 링크를 내부 콘텐츠로 변환하는 UX 마찰이 이탈 원인이 되지 않는다
