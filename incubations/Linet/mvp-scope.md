# MVP Scope — Linet

## 핵심 플로우 (3개 이하)

### Flow 1: 콘텐츠 작성 및 피드 노출
- 사용자가 140자 이내 한 줄을 입력한다.
- LLM이 자동으로 태그를 추천한다.
- 전송 시 실시간 피드 상단에 즉시 반영된다.

### Flow 2: 태그 기반 탐색
- 피드에서 태그를 클릭하면 해당 태그 기반 필터링 피드로 이동한다.
- 태그 검색 및 자동완성을 제공한다.

### Flow 3: 멘션(콘텐츠 간 참조)
- 💬 클릭 시 해당 콘텐츠를 멘션하는 입력창이 열린다.
- `>><contentID>` 형식으로 콘텐츠 간 연결이 생성된다.
- 멘션된 원글의 멘션 수가 갱신된다.

## Out-of-Scope (MVP에서 제외)

- 사용자 프로필 페이지
- DM (1:1 메시지)
- 알림 시스템
- 사용자 팔로우/팔로워
- 이미지/영상 업로드
- 외부 링크 직접 노출 (링크는 내부 콘텐츠로 변환)
- LLM 요약 기능 (비용 이슈)
- 모바일 앱 (웹 우선)

## 검증 기준 (측정 가능)

| 항목 | 기준 |
|---|---|
| 콘텐츠 작성 완료율 | 입력창 클릭 → 전송 완료 > 60% |
| 태그 자동완성 활용률 | 전체 작성의 40% 이상에서 LLM 태그 수용 |
| 멘션 사용률 | DAU의 20% 이상이 멘션 기능 사용 |
| 재방문율 | 가입 사용자의 40% 이상 D+1 재방문 |
