# Experiment Notes — Linet

## 핵심 가설

### 가설 1: 한 줄 제약이 생산 부담을 낮춘다
**가설**: 140자 제한이 있으면 사용자가 글을 더 자주, 더 부담 없이 작성한다.
**검증 방법**: 최초 7일간 1인당 평균 작성 수 측정. 목표: 1일 1개 이상.
**판단 기준**: 주간 작성 수가 감소하지 않으면 가설 채택.

### 가설 2: 태그 중심 탐색이 콘텐츠 발견을 개선한다
**가설**: 사용자 프로필이 아닌 태그를 중심으로 탐색하면 더 넓은 콘텐츠를 발견한다.
**검증 방법**: 태그 클릭 → 새 콘텐츠 소비(공감/멘션) 전환율 측정.
**판단 기준**: 전환율 > 20%.

### 가설 3: 실시간 피드가 재방문 동기를 만든다
**가설**: 5초 단위의 실시간 업데이트가 "지금 뭔가 일어나고 있다"는 감각을 준다.
**검증 방법**: 세션 당 평균 피드 체류 시간 측정.
**판단 기준**: 세션 체류 시간 > 3분.

## 미해결 질문

- LLM 자동 태깅의 정확도가 충분한가? (사용자가 태그를 수정하는 비율이 < 30% 이어야 함)
- 멘션 기능이 실제로 사용되는가, 아니면 단순 피드 소비로 끝나는가?
- 한 줄 제약이 불편함으로 인식되는 임계점은 어디인가?
