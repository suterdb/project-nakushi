# Experiment Notes — Linet

## Hypotheses to test
- H1: 사람들은 140자 한 줄 제한이 오히려 작성 마찰을 낮춰준다고 느낄 것이다
- H2: LLM 자동 태그가 수동 태그보다 사용자 만족도가 동등하거나 높을 것이다
- H3: 사용자 노출 최소화(팔로우 없음)가 이탈 원인이 되지 않는다
- H4: 콘텐츠 멘션(`>>ID`)이 자연스럽게 사용된다 (별도 교육 없이)

## Experiments
- E1 (H1 검증): 랜딩 페이지 + 간이 입력 폼 → 첫 방문자 작성 시도율 측정
  - 기준: 방문자 중 30% 이상 입력 시도
  - 방법: 별도 설명 없이 입력창만 노출
- E2 (H2 검증): 샘플 문장 50개 → 자동 태그 생성 → 5명 사용자 적절성 평가
  - 기준: "적절하다" 응답 70% 이상
  - 방법: A/B 없이 단순 만족도 인터뷰
- E3 (H3 검증): 초기 사용자 5~10명 인터뷰
  - 기준: "누가 썼는지 몰라도 괜찮다" 과반
- E4 (H4 검증): 2주 베타 후 멘션 사용 비율 측정
  - 기준: 전체 게시물의 15% 이상 멘션 포함
