# Problem — Linet

## 문제 정의

소셜 미디어는 길고 복잡한 콘텐츠를 요구한다.
사용자는 생각을 짧게 표현하고 싶지만, 기존 플랫폼은 긴 글과 이미지 중심이다.
텍스트 중심의 가벼운 소통 공간이 없다.

**핵심 문제**: "한 줄"로 충분히 소통할 수 있는 커뮤니티가 없다.

## 타겟 사용자

- 짧은 생각을 공유하고 싶지만 트위터/X의 정치적 분위기가 불편한 사용자
- 텍스트 중심의 가벼운 소통을 원하는 사용자
- 관심사 기반으로 콘텐츠를 탐색하고 싶은 사용자

## 성공 기준 (검증 기준)

- 첫 주: 10명 이상의 사용자가 자발적으로 콘텐츠를 작성한다.
- 재방문율: 등록 사용자의 40% 이상이 다음 날 재방문한다.
- 한 줄 제약이 "제한"이 아닌 "매력"으로 느껴진다는 사용자 피드백.

## 핵심 가설

> 한 줄 제약이 콘텐츠 생산의 부담을 낮추고, 오히려 소통의 밀도를 높인다.
