# Linet - 단 한줄 입력 커뮤니티 서비스 기획서 (업데이트)

## 서비스 개요

* **Linet**: 단 한 줄로 소통하는 커뮤니티.
* 모든 컨텐츠는 **단 한 줄**로 작성.
* **텍스트 중심**(외부 링크 직접 노출 금지; 참고 링크는 내부 컨텐츠로 변환 후 멘션으로 참조).
* LLM을 활용한 **자동 태깅**.
* 사용자가 원할 경우 **자동완성 기반 수동 태그 입력 가능**.
* 사용자 중심 노출은 최소화하며, 태그를 중심으로 운영.
* 멘션은 **사용자가 아닌 컨텐츠**에 대해서만 가능.

## 태그 및 멘션 구분

### 태그 (Tag)

* **역할**: 컨텐츠를 표현하는 주요 키워드.
* **생성**: LLM이 자동 생성하거나, 사용자가 자유롭게 입력 가능.
* **관리**: 내부적으로 유사 태그를 그룹화하여 관심사 기반 피드 구성에 활용.
* **활용**: 검색, 추천, 관심사 피드 구성에 사용.
* **표시**: 본문 하단에 표시.

### 멘션 (Mention)

* **형식**: `>><컨텐츠ID>`
* **대상**: 컨텐츠 단위만 가능(사용자 멘션 불가)
* **동작**: 기본적으로 원문 비노출, **펼치기**로 확인 가능.
* **목적**: 컨텐츠 간 연결 및 참조.
* **작성**: 한 줄 규칙 내에서 멘션 포함 가능.

## 메인 피드 구성

* **목표**: “지금도 컨텐츠가 계속 생산되고 있다”는 실시간성 전달.
* 최신순 피드가 기본이며, 5초 단위로 신규 컨텐츠를 상단에 자연스럽게 추가.
* 채팅처럼 급격히 올라가지 않고, 읽기 좋은 속도로 부드럽게 업데이트.
* 각 줄은 다음과 같은 형태:

  ```
  #태그 한 줄 내용  ❤️ 12  💬 3  ✖️
  ```

  * **❤️**: 클릭 시 공감(숫자 증가, 애니메이션 효과)
  * **💬**: 클릭 시 해당 컨텐츠를 멘션하는 입력창 오픈
  * **멘션 숫자**: 클릭 시 멘션된 컨텐츠 목록 표시
  * **✖️(X 버튼)**:

    * **작성자**: 오리지널 컨텐츠 삭제
    * **소비자**: 해당 컨텐츠를 자신의 피드에서만 숨김

## 작성 플로우

1. 하단 고정 입력창 클릭 시 확장.
2. 140자 제한 한 줄 입력.
3. LLM 추천 태그 노출(자동완성 지원).
4. 전송 시 피드 상단에 즉시 반영.

## 멘션 작성 플로우

1. **💬 클릭** → 멘션 포함된 입력창 자동 오픈
2. 작성 후 전송 시 멘션 관계 연결, 원글 멘션 수 업데이트

## 태그 탐색

* 태그 클릭 시 해당 태그 기반 피드 필터링.
* 태그 검색 및 자동완성 제공.

## 리액션

* ❤️ 클릭 시 공감수 증가(애니메이션).
* 재클릭 시 취소 가능.

## UI 및 인터랙션 플로우 시안

### 메인 피드 화면

* 화면 전체를 피드로 구성, 상단 GNB 없음.
* 각 컨텐츠 카드: `#태그 내용 ❤️ 공감수 💬 멘션수 ✖️`
* 태그 클릭: 해당 태그 기반 필터링 피드로 이동.
* ❤️ 클릭: 즉시 공감 반영 + 애니메이션.
* 💬 클릭: 해당 컨텐츠 멘션 작성창 팝업.
* 멘션 숫자 클릭: 멘션된 컨텐츠 목록 표시.
* ✖️ 클릭:

  * 작성자: 원본 컨텐츠 삭제
  * 소비자: 해당 컨텐츠를 자신의 피드에서 숨김

### 실시간 업데이트 방식

* 페이지 진입 시 최신 컨텐츠 로드.
* 5초 주기 신규 컨텐츠 로드 → 상단 부드럽게 추가.
* 스크롤 위치 고정, 읽는 흐름 방해 최소화.

### 작성 및 멘션 플로우

* 하단 고정 입력창 → 클릭 시 확장.
* 멘션 클릭 시 자동으로 멘션 코드 포함.
* 등록 시 피드 상단에 즉시 반영, 원글 멘션 수 갱신.

## 링크 처리 정책

* **외부 링크 직접 노출 금지**.
* **참고 링크는 내부 컨텐츠로 변환 후 멘션으로 참조**.
* **유해 URL 필터링** 및 **중복 방지**.
* **외부 원문 비노출 원칙**. 단, 이용자 편의를 위해 원문 제목 또는 간략한 메타 정보(예: 페이지 타이틀)를 함께 제공.

  * HTML `<title>`만 단순 노출하는 방식은 지양.
  * LLM 요약은 비용 문제로 상시 적용하지 않음.
  * 향후 필요 시 선택적 요약 기능 제공 가능.
