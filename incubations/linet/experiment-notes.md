## Key Assumptions to Test

우선순위 순으로 정렬. 가장 위험한 가정부터 검증한다.

### 1. "사람들은 한 줄로 충분하다고 느낄 것이다"

- **위험도**: 높음
- **검증 방법**: 랜딩 페이지 + 간이 입력 폼으로 실제 작성 시도 수집
- **기준**: 첫 방문자 중 30% 이상이 실제로 무언가 입력한다

### 2. "LLM 자동 태그가 사용자 기대를 충족할 것이다"

- **위험도**: 높음
- **검증 방법**: 샘플 문장 100개 → 자동 태그 생성 → 사용자 만족도 평가
- **기준**: "이 태그가 적절하다" 응답 70% 이상

### 3. "사용자 노출 최소화가 이탈 원인이 되지 않는다"

- **위험도**: 중간
- **검증 방법**: 초기 사용자 인터뷰 (5~10명)
- **기준**: "누가 썼는지 몰라도 괜찮다"는 반응이 과반

### 4. "콘텐츠 멘션이 자연스럽게 사용된다"

- **위험도**: 낮음 (기능 자체는 단순)
- **검증 방법**: 2주 베타 후 멘션 사용 비율 측정
- **기준**: 전체 게시물의 15% 이상이 멘션 포함
