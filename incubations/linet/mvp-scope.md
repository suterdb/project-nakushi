# MVP Scope — Linet

> One page. No exceptions.

---

## MVP Definition

**단 한 줄로 생각을 올리고, 태그로 발견되고, 멘션으로 연결된다.**

이것이 전부다. 그 이상은 MVP가 아니다.

---

## In Scope

### Core Loop

| 기능 | 설명 |
|------|------|
| 한 줄 작성 | 140자 제한 입력창 (하단 고정) |
| LLM 자동 태깅 | 전송 시 태그 자동 생성 및 노출 |
| 실시간 피드 | 최신순, 5초 주기 자동 갱신 |
| 공감 (❤️) | 클릭 즉시 반영 + 재클릭 취소 |
| 멘션 (`>>ID`) | 콘텐츠 간 연결, 원문 비노출 기본 |
| 태그 필터링 | 태그 클릭 시 해당 피드로 이동 |
| 숨김 / 삭제 | 작성자: 삭제 / 소비자: 내 피드에서 숨김 |

### 링크 처리

- 외부 링크 → 내부 콘텐츠로 변환 후 멘션 참조
- 유해 URL 필터링
- 페이지 타이틀(메타) 단순 노출 (LLM 요약 제외)

---

## Out of Scope (MVP에서 제외)

- 사용자 팔로우 / 팔로워
- DM / 채팅
- 사용자 멘션 (`@user`)
- LLM 링크 요약 (비용 문제로 MVP 이후 선택적 적용)
- 알림 시스템
- 모바일 앱 (웹 우선)
- 수동 태그 자동완성 (기본 자동 태깅 검증 후 추가)

---

## Validation Criteria

MVP가 성공했다고 판단하는 기준:

1. 사용자가 **앱 진입 후 30초 이내** 첫 줄을 작성한다
2. **LLM 자동 태그 정확도** 체감 만족도 70% 이상 (초기 사용자 인터뷰)
3. 동일 태그 내 **멘션 연결**이 자연스럽게 발생한다
4. 피드가 **비어 보이지 않는다** (콘텐츠 밀도 유지)

---

## Tech Assumptions

- LLM 태깅: 외부 API 활용 (초기 비용 감수)
- 실시간 피드: 폴링 방식 (5초 주기), WebSocket은 이후 단계
- 인증: 최소화 (소셜 로그인 1종 우선)
- 저장: 단순 RDBMS, 태그 인덱싱 필수
