# Raw Plan — Mirror

## 아이디어 출처

"또 다른 나의 자아와 대화할 수 있는 서비스를 기획해볼 수 있지 않을까?"

Nakushi 인큐베이션 세션 중 제안된 아이디어.
Linet이 "타인과의 연결"을 다룬다면, Mirror는 "나 자신과의 연결"을 다룬다.

## 핵심 컨셉

사용자가 자신이 남긴 텍스트 데이터(일기, 메모, 대화 등)를 기반으로,
LLM이 "나"의 페르소나를 구성하고, 사용자는 그 자아와 대화한다.

## 유즈케이스 후보

- 의사결정 시뮬레이션: "이직 제안 받았는데, 나라면 어떻게 판단했을까?"
- 자기 성찰: 과거 나의 생각과 현재 나의 생각이 어떻게 달라졌는지 대화로 확인
- 감정 해소: 말 못 했던 것들을 "나 자신"에게 털어놓기
- 회고 파트너: 주간 회고를 "나"와 함께 진행

## 데이터 소스 후보

- 카카오톡 대화 내보내기
- 노션 / 일기 텍스트
- SNS 게시물
- 유저가 직접 입력하는 Q&A (가치관, 습관, 의견)

## 기술 방향 (초안)

- 텍스트 임베딩 + 프로파일링으로 페르소나 레이어 구성
- 말투 스타일, 논리 패턴, 관심사/가치관 맵 추출
- 대화 인터페이스: 채팅 UI, LLM이 "나"로서 응답

## 미결 질문

- "나"의 어떤 시점을 기준으로 할 것인가? (현재 vs 과거 vs 이상적 미래)
- 데이터 프라이버시 처리 전략
- 서비스 형태: SaaS vs 로컬 앱 vs 1회성 세션
